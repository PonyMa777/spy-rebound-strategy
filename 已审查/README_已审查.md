# 当前规则更新（2026-10-20）

以下规则取代下方旧版说明中的价格、退出规则和历史业绩：
- 信号价格统一为 (Open + Close) / 2，均线、走势段高低点、力度和买点均使用它。
- 信号出现当天直接买入：信号要用当天收盘价才能确认，所以按信号日收盘价加滑点成交（实盘相当于收盘前几分钟估算信号并下单，有执行误差）；使用现金的50%。
- 仅按实际买入成交价设置 +1.5% 止盈限价、-1% 止损触发价。两者为股价毛收益，手续费另计。
- 原1S/2S/3S、结构止损及时间退出不再触发卖出；结构信号仅保留作研究。
- 必须提供 Date,Open,High,Low,Close，价格口径一致。现有缺Low的数据不能运行新版；不得以开收盘价伪造最低价。
- 开盘跳空先处理；跳空跌破止损按开盘价扣滑点卖出，亏损可能超过1%。盘中触及止损按止损价扣滑点成交。
- 同日High和Low同时触及两条线且开盘未先触发时，保守假设先止损。买入当天不会退出（当天的最高/最低价发生在收盘买入之前），止盈止损从下一交易日开始生效。止盈假设限价足量成交。
- 平均价格只用于信号；实际成交按OHLC模拟，账户收盘估值仍用Close。
- 下方旧版回测数字已失效，不代表当前规则表现。运行 testChan 验证新规则。
- 力度仍为均线距离的面积代理指标，没有改成完整缠论。

## 实现了什么（对应课次）

| 概念 | 书中定义 | 本实现（日线） |
|---|---|---|
| 体位（第 11 课） | 短均线在长均线上/下 | MA5 > MA10 为多头，MA5 < MA10 为空头；两条线相等时延续前一天的状态 |
| 走势段 / 缠绕（第 11、15 课） | 用均线缠绕把走势分成可比较的段 | 每次 MA5 与 MA10 交叉，结束上一段。只在交叉当天收盘后才知道这一段已经完成 |
| 力度（第 15 课） | 两次缠绕之间均线围成的面积，或平均力度 | `forceMeasure='area'`：段内 sum\|MA5−MA10\|；`'mean'`：面积 ÷ 天数 |
| 趋势（第 15 课："没有趋势，没有背驰"） | 高低低低 / 高高低高 | 下跌：本段低点 < 前一同向段低点，且中间反弹段高点 < 更早反弹段高点；上涨反之 |
| **底背驰 → 第一类买点 1B**（第 12、15 课） | 同级别同向，后一段创新低但力度减弱 | 下跌趋势成立 + 本下跌段力度 < 前一下跌段力度；在金叉当天收盘产生信号 |
| **顶背驰 → 第一类卖点 1S** | 镜像 | 上涨趋势成立 + 本上涨段力度 < 前一上涨段力度；在死叉当天产生信号 |
| **第二类买点 2B**（第 12、17 课） | 第一类买点后第一次回调不破前低 | 1B 之后紧接着的那一段下跌，其低点 > 1B 段低点 |
| 第二类卖点 2S | 镜像 | 1S 之后第一次反弹的高点 < 1S 段高点 |
| 中枢 [ZD, ZG]（第 17、20 课） | 至少三个连续次级别走势的重叠区 | 离开段之前的三段：ZG = 三段高点中的最小值，ZD = 三段低点中的最大值，要求 ZG > ZD |
| **第三类买点 3B / 真突破**（第 20 课） | 离开中枢后第一次回试不回中枢 | 上涨段高点 > ZG，紧接着的回调段低点 > ZG |
| **假突破**（第 18、20 课） | 回试重新进入中枢 = 中枢延伸，不是突破 | 上涨段高点 > ZG，但回调段低点 ≤ ZG；记在 `FalseBreak` 列，不交易 |
| 第三类卖点 3S | 镜像 | 下跌段低点 < ZD，紧接着的反弹段高点 < ZD |
| 结构止损（第 13 课） | 交易逻辑失效时退出，而不是按随意的百分比 | 1B：收盘跌破背驰段低点；2B：收盘跌破 1B 低点；3B：收盘回到 ZG 以下（假突破） |

## 交易规则

- 只做多。收盘出信号，下一交易日开盘按开盘价 +0.05% 滑点成交；用当时现金的 50%，手续费 0.05%，整股向下取整。和原策略一致。
- 退出条件：任何卖点（1S/2S/3S）、收盘跌破结构止损位、或持仓超过 `maxHoldDays`（默认关闭）。退出同样在下一交易日开盘执行。
- 每次只持有一笔仓位，持仓期间出现的买点不会加仓。

## 和缠论原文的偏差（审查重点）

1. **没有笔和线段**。第 1–20 课还没有定义笔，这里用 MA5/MA10 交叉代替次级别走势，属于第 11–15 课的"入口版本"。
2. **只有单一级别**。没有做第 14 课的"大级别定方向，次级别定位置"。
3. **只用收盘价**。数据里没有 Low 列，每段的高低点用段内收盘价的最高和最低值代替。
4. **力度只用均线面积**，没有用 MACD 辅助。
5. **没有处理中枢延伸和级别扩张**（第 18、20 课）。中枢每次都用最近三段重新计算。
6. **没有第 16 课的"进入盘整就退出"规则**。
